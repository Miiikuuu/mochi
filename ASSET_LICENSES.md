# Asset and dependency licensing inventory

This inventory distinguishes source preservation from permission to distribute.
The code license does **not** supply missing rights for imported artwork.

| Category / path | Status | Staging / public package policy |
| --- | --- | --- |
| `characters/**` (Shanbi, Angelina, Jacinta, Timeslot, Mutsumi, videos, extracted Spine/PNG art) | Redistribution permission not established in this repository | Excluded; never infer permission from an included player/runtime license |
| Imported ZIP/HTML/MP4/PNG reference materials at repository root | Authorization not established | Excluded |
| `assets/manager/portraits/**` | Derived character artwork; unverified | Excluded |
| `assets/bubbles/lime-*` and other imported DIY bubble designs | Unverified artwork provenance | Excluded |
| `assets/bubbles/default/**` | Mochi-authored CSS, layout and vector material; Apache-2.0 | Included |
| `assets/brand/**`, user-provided logo PNG and embedded raster SVG | Separate user artwork; redistribution authorization not established | Excluded from staging; source development keeps the existing logo |
| `assets/icons/**`, `assets/manager/icons/**` | Mochi-authored interface vectors/CSS; Apache-2.0 | Included |
| Third-party plugin icons | No redistribution assumption | Replaced in staging by the original procedural release icon |
| `packaging/icons/io.mochi.Manager.svg` | Original Mochi vector; Apache-2.0 | Included |
| Procedural `mochi-dot.mochi` generated by `build-package.py` | Original Mochi demo, Apache-2.0 | Included; no source character art is used |
| Character-pack fonts | See each pack's font license; not needed by installed UI | Excluded; use distribution `fonts-noto-cjk` |
| `tests/fixtures` decoder vectors and `examples/{neko,animated-neko,interactive-neko}` diagnostic sprites | Original 1×1 white pixel, 8×8 color diagnostics and generated codec vectors; Apache-2.0 | Public Source only, exact SHA-256 allow-list; no imported character art |
| System fonts / GTK icons | Distribution-owned dependencies | Not copied into the archive |
| AppStream metadata | CC0-1.0 | Included |
| Spine 3.8 runtime code | Esoteric Software Spine Runtimes License; see vendor LICENSE | Excluded from Public Source and default no-Spine binaries; private full staging builds include license and notice, with public distribution rights still unconfirmed |
| npm / Cargo dependencies | Respective upstream licenses and lockfiles | Preserve npm license files; audit dependency notices before public release |

The allow-list in `scripts/build-package.py` is authoritative. Adding a character,
bubble, font or brand asset requires an exact source, copyright holder, license,
redistribution evidence, attribution and an update to the packaging check.
Neither a successful CI run nor a package SHA-256 constitutes a license grant.
