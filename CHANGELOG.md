# Changelog

## 0.9.1 — unreleased staging

- History-free Public Source allow-list, no-Spine renderer lane and dependency SBOM.
- Signed staging hash manifests with explicit ephemeral signer scope.
- Existing-user migration preserves missing-resource Themes; explicit Library adoption.
- Unified product version, system Node bridge validation and package correctness checks.

- Role-scoped Sessiond capabilities, sanitized status, revision-aware events,
  CLOCK_BOOTTIME and explicit protocol negotiation.
- Confined third-party plugins cannot obtain ChatGPT session authority.
- Relocatable installed Manager/Renderer/Sessiond layout and systemd user socket
  activation; pending delivery becomes uncertain before graceful replacement.
- Reproducible asset-filtered staging archive and optional Debian package.
- Apache-2.0 for original code; asset provenance inventory and release gates.

## 0.9.0 — development baseline

- GTK4 Manager default; GTK3 Legacy fallback retained for transition.
- Themes, Library, Connections and Settings with draft/apply separation,
  revision conflicts, resource leases and transaction recovery.
- Independent in-memory Sessiond binding across Theme and Manager restarts.
