# Community code of conduct

Treat contributors and users with respect. Discuss code and behavior rather than
attacking people. Harassment, threats, discrimination, sexualized conduct,
doxxing, spam and publishing private conversations or credentials are prohibited.
Respect boundaries when someone asks a conversation or contact to stop.

Maintainers may edit/remove harmful contributions, close discussions, or restrict
participation proportionately. Concerns may be reported privately to repository
maintainers through an available private GitHub channel; do not publish another
person's private information in a public report. Maintainers should protect
reporter confidentiality, explain enforcement when appropriate, and allow an
appeal through the same private channel.

This policy applies to repository issues, reviews, discussions and project spaces.
It is an original project policy, not an adoption of a named external covenant.
