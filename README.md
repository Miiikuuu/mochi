# Mochi Public Source candidate

This audited staging tree has no private history or imported artwork. It is not a public Release.

Build the default Sprite renderer with `cargo build --release -p mochi-desktop`.
Package with `/usr/bin/python3 scripts/build-package.py target/stage --archive target/mochi.tar.gz --deb`.
The installed demo uses original Mochi Dot and Default Bubble.
See docs/PUBLIC_SOURCE.md for auditing and licensing boundaries.
